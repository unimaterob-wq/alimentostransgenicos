# Mini-game educativo: Alimentos Transgênicos

Jogo educativo 2D sobre biotecnologia agrícola e alimentos transgênicos.

## Como executar localmente
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador atualizado.
3. Clique em **Iniciar Jogo**.

O jogo usa Tailwind CSS e fontes do Google Fonts via CDN, então alguns elementos visuais dependem de conexão com a internet. A lógica principal do jogo está no próprio `index.html`.

## Publicar com GitHub Pages
1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html` para a raiz do repositório (e este `README.md`, se quiser).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na seção **Pages**. O link normalmente segue o formato `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Controles
- Mover: `W`, `A`, `S`, `D` ou as setas do teclado.
- Interagir/avançar diálogos: `E`.
- Também há controles de toque para dispositivos móveis.
